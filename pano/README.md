# 360° 環景照片（自架）

3D 校園的「進入 360° 實景」會**優先**讀取本資料夾的照片，找不到才改用 Google 地圖的相片網址。
Google 地圖相片網址是有時效的簽章連結，過期後會回 403，而且不允許其他網站用 WebGL 讀取，所以畫面會變黑。
把照片放在這裡（與網站同網域）就能永久穩定顯示。

## 規格

- 格式：等距長方投影（equirectangular）全景 JPG，**寬:高 = 2:1**（例如 4096×2048 或 5504×2752）
- 建議寬度 4096 px、JPG 品質 80，每張約 1–2 MB（太大會讓手機載入很慢）
- 檔名：`<景點代號>.jpg`，例如 `spot-12.jpg`
